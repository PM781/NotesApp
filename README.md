# Notes App

A responsive note-taking app built with React for the Week 04 minor project.

## Features
- Create, edit, and delete notes
- Search note titles and content
- Categorize and filter notes
- Show the last-updated timestamp
- Save notes with browser Local Storage

## Technologies
React, JSX, JavaScript ES6+, Vite, CSS, `useState`, `useEffect`, and `useMemo`.

## Setup
Install Node.js. In this folder, run:

```bash
npm install
npm run dev
```

Open the local URL printed in the terminal.
